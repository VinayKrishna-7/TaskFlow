# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The TaskFlow team takes the security of our project seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do not create a public issue**.
2. Please report security issues by opening a private security advisory on GitHub or by contacting the project maintainer at [GitHub Profile](https://github.com/VinayKrishna-7).
3. Include detailed instructions on how to reproduce the vulnerability.
4. We will acknowledge receipt of your vulnerability report promptly and provide an estimated timeline for remediation.
